02 Standard API Specification مشخصات وب‌سرویس API

Batch Ingestion Endpoint وب‌سرویس دریافت دسته‌ای داده‌ها

Ingests binary and JSON telemetry buffers into the worker pipeline for background verification. بسته‌های بافر باینری و داده‌های تله‌متری را جهت پردازش پس‌زمینه در صف پردازش قرار می‌دهد.

POST /api/v2/telemetry/ingest

03 Code Implementation پیاده‌سازی و نمونه کد

Client implementation demonstrating asynchronous ingestion with automatic token refresh: نمونه پیاده‌سازی کلاینت جهت ارسال ناهمگام با تمدید خودکار توکن:

TypeScript 
export async function ingestTelemetry(docId: string, token: string): Promise<boolean> {
  const response = await fetch('/api/v2/telemetry/ingest', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({ document_id: docId, batch_size: 256, flush_immediate: true })
  });

  return response.ok;
}
