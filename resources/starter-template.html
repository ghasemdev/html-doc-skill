02 · API Specification

Sync Data Batch

Ingests data payloads into the processing queue.

POST /api/v2/data/sync
Parameter Type Required Description Example
session_token string Required Cryptographic authorization token "tok_9981"
JSON Request 
{
  "document_id": "doc_101",
  "sync_all": true
}
JSON Response (200 OK) 
{
  "status": "SUCCESS",
  "records_count": 42
}

03 · Code Implementation

JavaScript 
// Code is always strictly LTR
export async function syncBatch(token) {
  return await fetch('/api/v2/data/sync', { headers: { Authorization: token } });
}
